# Savora Restaurant Template

Savora is a polished static restaurant template. It presents a warm wood fired dining room with hero art, tabbed menu, story, gallery, guest reviews, reservation form, visit info, and footer. Pure HTML plus CSS plus vanilla JS. No build step. No external images. All art is CSS and inline SVG.

## Run

Serve the folder then open in a browser:

```
python3 -m http.server 8000
```

Then visit `http://localhost:8000/`

You can also open `index.html` directly in a browser with no server.

## Files

```
index.html   Page structure for all five sections
styles.css   All styling, palette, layout, responsive rules
script.js    Nav, tabs, scroll reveal, reservation validation
README.md    This guide
```

## Features

1. Sticky nav with mobile menu and smooth scroll
2. Hero with calls to action, info badges, and CSS plate art
3. Menu with tab switching for Starters, Mains, Desserts, Drinks
4. Story plus gallery strip plus guest reviews with scroll reveal
5. Reservation form with validation and success state plus hours and footer

## Palette

Cream #FFF8F0, ink #1C1410, accent #B5451B, gold #E9A23B. Solid colors only.

## Notes

Responsive at 1024, 768, and 480. Type scales with clamp. Just copy the folder to reuse for any restaurant brand.
